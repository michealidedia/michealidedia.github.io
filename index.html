Mapping the Nigerian impact investing market and sizing the capital flows

The first comprehensive attempt to quantify impact capital flowing into Nigeria. The problem is data-scarce by nature: there is no deal register, disclosure practice varies by fund, and the same naira can be counted three times if nobody fixes the definitions first.

  • Designed the research protocol and the metric taxonomy that keeps assets under management, committed capital and deployed capital strictly separate, so no two figures in the report are silently measuring different things.
  • Built the verified evidence base across roughly 62 investor organisations from a corpus of about 332 primary sources: development finance institution reports, fund disclosures and portfolio databases. Every extracted figure carries its printed page reference and a confidence grade.
  • Built the primary collection system running across a 158-organisation respondent base: a 42-screen instrument with ten branching logic rules, feeding a live multi-tab data store through an automated response parser.
  • Run the outreach cycle myself, sequenced with tiered escalation and follow-up, alongside a contact enrichment pipeline that resolves organisations to verified addresses.

Systems I build

Most research teams lose weeks to work a machine should be doing. I build the machine, then hand it over with a written build guide so it keeps running when I am not there.

Research integrity

The part of the job that does not show up in a deliverable, and the part I would want to be judged on.

  • A wrong number stops the analysis. I built a source-parsing notebook in which every published figure is re-derived at run time from its original data file, checked in code against an independently published anchor and logged in a provenance ledger. If a figure fails its check the run halts rather than quietly producing a chart.
  • Confidence is graded per figure. Classification rules and per-figure confidence grading keep numbers comparable and traceable. Where two credible sources disagree, the discrepancy is preserved and flagged rather than resolved quietly to make the table look tidy.
  • I have taken correction publicly. On a published report I responded to a 22-point external methodological audit, verified each flag against primary source, and revised the analysis where the criticism held. One finding did not survive correction and I reported it as such instead of retaining it.
  • Ethics is procedural, not aspirational. Work under national ethical approval, PEPFAR data quality standards and WHO-aligned chain-of-custody documentation, with consent and confidentiality protocols applied throughout.

The FRAME Method

A reusable model I designed for how I take on an assignment, from framing the question through to handing over work that runs without me. It applies whether the assignment is a study, an evaluation, an analysis or a system.

FFrame the question

Agree the real question and what evidence would answer it, before committing to a method.

RRules and design

Fix definitions, classification rules and design decisions before the work starts.

AAcquire the evidence

Build and gather it hands on: instruments, fieldwork, primary sources.

MMeasure and verify

Analyse, then check each result against its source and flag confidence explicitly.

EEmbed for use

Document and automate so the work runs again without me, and translate it for whoever must act.

The loop closes: what the work reveals re-frames the next question. In practice the fifth stage is the one most projects skip, and it is the reason so much analysis has to be rebuilt from scratch the following year.
