## Privacy

The screenshots come from live study documents. Names, phone and ID numbers, addresses, bank and pay details, file names, document links, transcript text, findings and quotes are covered with solid bars, so nothing underneath can be recovered. In the fieldwork photo, participants' faces are blurred and the phone watermark is cropped out. Camera data is removed from every photo.

Keep it that way if you add images: no respondent data, no unpublished findings, no children, and no personal contact or bank details.

## Changing the page

Edit `index.html` in GitHub (pencil icon), then Commit changes. The site updates in about two minutes.
